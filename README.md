# Keych

Keych is a small wearable electronics project built around an ESP32-C3. It features a small OLED display and physical buttons, all powered by a rechargeable LiPo battery.

## Features

* ESP32-C3 SuperMini
* SSD1306 OLED display
* 2 × 6×6 mm push buttons
* 3.7V LiPo battery
* Buck converter
* Battery connector
* Compact wearable design

## Hardware

The ESP32-C3 handles the main processing and controls the OLED display and buttons. The LiPo battery provides portable power, with the buck converter regulating the voltage for the electronics.
